Bachelor's Thesis — University of Stavanger in collaboration with ABB Bryne (2026)

Designed and implemented a simulation framework enabling ABB's Virtual IPS controller to execute closed-loop tests against a virtual industrial process instead of physical hardware. The framework integrates a C++ controller, C# middleware, MQTT communication, Windows shared memory, and a Python process simulator.

  • Replaced FPGA hardware I/O with Windows shared memory without modifying controller software.
  • Developed a C# MQTT proxy using MQTTnet.
  • Created a Python RLC process simulator using paho-mqtt.
  • Achieved 1.24 ms average MQTT round-trip latency.
  • Validated simulation with only 0.29 V mean absolute error over ±10 V.
  • Implemented automatic broker reconnection and fault tolerance.

Personal Project – ESP32-S3 / ESP-IDF 2026

Designed and implemented a complete closed-loop speed controller for a standard 4-wire PC fan. The system combines PWM drive, real-time tachometer feedback, a custom OLED user interface, local rotary-encoder control and a web-based remote interface with live RPM streaming.

  • PWM speed control of a 12 V 4-wire fan using an IRLZ44N MOSFET (low-side switching).
  • Hardware tachometer reading with ESP32 pulse counter peripheral and exponential filtering.
  • Custom SSD1306 OLED driver featuring an animated fan icon, duty-cycle bar, live RPM and IP address.
  • Rotary encoder for local duty adjustment and power on/off toggle.
  • Wi-Fi web interface (HTTP + WebSocket) for remote control and real-time RPM updates.
  • Thread-safe shared state protected by FreeRTOS mutex for concurrent access from encoder, web server and main loop.
  • Regulated power supply.
